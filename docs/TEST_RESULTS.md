## 실제 문제은행으로 실행한 항목

실제 JSON에서 60개를 추출하여 고유 ID, 21/39 내부 영역 배분, 모든 세부 주제 배분과 60분 종료시각을 확인했습니다. 답을 변경하고 3개 응답 후 새로고침하여 문제 순서·답안·종료시각이 유지되는지 확인했습니다. 실제 정답 정보를 기준으로 36개 정답·10개 오답·14개 미응답을 UI에서 입력해 **60.0점·합격**, 오답·미응답 해설 24개, 출처 링크, 제출 결과 재복원을 확인했습니다. 다시 시험을 시작하면 다른 순서와 빈 답안을 얻습니다.

실제 은행에서 가장 긴 문제의 해설·근거를 펼쳐 PC와 모바일에서 가로 넘침이 없는지 확인하고 화면을 캡처했습니다. 선택지는 44px 이상 터치 영역을 검사했습니다. 브라우저 스크립트 오류도 확인했습니다.

## 기능 경계 검사

별도의 합성 fixture는 테스트 러너에서만 사용합니다. 35/36개 합격 경계, 점수 반올림, 60분 경과 자동 제출, 만료 후 재접속, 제출 후 답안 잠금, 손상된 저장소, 저장소 접근 거부, 미응답 이동, 프로젝트 하위 경로 및 iframe을 검사합니다. 합성 문항은 문제은행이나 배포 산출물에 포함하지 않습니다.

첫 브라우저 검사에서 검색어 ‘원자번호’가 새 은행에서는 2개 문항에 나타났지만 기존 테스트가 1개만 가정하여 실패했습니다. 검색 결과를 확인하고 기대값을 수정한 뒤 최종 20개 검사를 통과했습니다. 초기 140개 원고 상태를 가정한 단위 검사도 최종 은행과, 별도로 만든 불완전·미승인 은행을 각각 검사하도록 갱신했습니다. 필요한 실패 조건을 없애지 않았습니다.

## 정확성 검토와 자동 검사의 차이

자동 검사는 정답의 학문적 정확성을 보증하지 않습니다. 출처의 짧은 인용문이 일치하더라도 해설 전체의 정확성이 자동 입증되지는 않습니다. 화학반응식의 원자 수 보존 또한 반응 조건·속도·소화 적응성 검토를 대신하지 않습니다. 내용 검토의 범위·교체 이력·내부검수의 한계는 [CONTENT_REVIEW.md](CONTENT_REVIEW.md)에 기록했습니다. 외부 전문가의 독립검수나 Q-Net 인증을 받았다고 표시하지 않습니다.
