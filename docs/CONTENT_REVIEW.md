# 문제은행 검수 기록

2026-10-19 기준 HM0001–HM1000, 실제 1,000개, 내부검수 후 출제 가능 1,000개, 대기·미작성 0개입니다. 영역 A 350개, B 650개이며 공식 110개 세세항목 모두에 문항이 연결되어 있습니다.

## 검수 의미와 범위

`verified`는 **Codex가 수행한 출처 대조 및 화학·법령 논리의 내부검수**입니다. 자격을 가진 외부 전문가의 독립검수나 공적 인증을 뜻하지 않습니다. 문항별 출처 연결, 정답·오답 구별, 조건·예외, 해설, 계산 및 의미 중복을 검토한 결과를 기록했습니다. 자동 파일 검사만으로 학문적 정확성을 인증하지 않습니다.

자료는 Q-Net 출제기준, 현행 대한민국 법령·소방청 고시와 고정 CC BY 4.0 판본의 OpenStax Chemistry 2e입니다. 모든 문항을 자체 제작 예상문제로 표시합니다. 법령 문항은 기준일에 확인한 시행본을 사용하며, 과거 2과목 체계나 과거 제5류 지정수량을 그대로 적용하지 않습니다. 화학 문항은 개념·조건을 검토하고 불확실한 특수 물성 수치를 추정하지 않았습니다.

## 수록 형태

- 처음 작성한 140개를 보존·재검토하면서 최초 60개 중 출처 확인이 충분하지 않은 특수 물성·화재 현상 문항은 근거를 확인할 수 있는 별도 학습 내용으로 수정했습니다. 수정 전 원고는 `review/initial-60-before-review.json`에 보존했습니다.
- 화학 용어 191개: 영어 정의와 한국어 설명을 대조했습니다. 중량분석법의 번역을 수정하고, 전자쌍 수만 다른 문항 하나를 옥텟 규칙 문항으로 교체했습니다.
- 계산 30개: 서로 다른 물리량·법칙·반응 계산 유형입니다. 여기에 CS₂ 몰질량과 법정 건축물 소요단위 계산이 있어 **총 32개를 별도 재계산 테스트**합니다.
- 소화·경보·피난 용어 93개: 해당 NFPC 정의 원문이 정의하는 용어를 묻습니다. 일반 건축물의 NFPC 기준을 위험물 제조소등에 무조건 대입하지 않도록 해설에 적용 범위를 설명했습니다.
- 법령 문언 복원 500개: 서로 다른 조항의 대상·조건·예외·안전 의무를 다룹니다. 보기의 법률적 의미를 자유 판단하는 문제와 구별하여 **원문의 빈칸을 복원**하도록 명시합니다.
- 유별 안전·물성·유기화학·운송 및 설비 적용 46개: 범위 누락 항목을 보강했습니다. 제6류 CO₂소화기의 조건부 적응성, 알칼리금속 과산화물의 금수성 예외 등을 구별했습니다.

법령 추출 중 표 열이 섞인 문제, 불완전한 참조, 같은 안전 결정을 시설명만 바꾼 문제는 교체했습니다. `review/legal-revisions.json`에 69회의 교체 이력을 남겼습니다. 같은 ID를 다시 고친 경우가 포함되므로 교체 횟수를 새 문항 수로 더하지 않습니다. 부표·PDF 페이지 위치도 다시 대조했습니다.

## 기록과 변경 통제

`data/questions.json`의 각 `review.evidence`에는 공식 항목 ID·페이지와 정확성 검토용 출처·위치·인용·스냅샷 해시·시행일이 있습니다. 인용은 근거의 발췌 또는 관련 개념의 문맥이며 모든 인용문 하나가 전체 정답을 단독으로 입증한다는 뜻은 아닙니다. 계산은 주어진 가정과 별도 수식으로 검산하고, 소화 적응성 표는 열·비고를 함께 읽었습니다.

`data/content-reviews.json`에는 1,000개 검토 결정과 문항 내용의 SHA-256 지문을 기록했습니다. 문항·보기·정답·해설·공식 항목이 바뀌면 기존 기록으로 배포 검증을 통과하지 못합니다. 새 내용에는 별도 재검토가 필요합니다. `data/sources.json`은 출처 자료 자체의 해시를 관리합니다.

## 중복 검사

정규화한 문제 내용, ID, 개념 키를 검사합니다. 반복되는 안내 문구와 출처 제목이 유사도를 부풀리지 않도록 본문을 비교하며, 숫자 치환 후 3-gram Dice 0.66 이상을 후보로 표시합니다. 숫자·문장부호만 바꾼 동일 형태도 검출하는 테스트가 있습니다.

남은 유사 후보 **14쌍**은 비교 후 서로 다른 학습 목표로 판정했습니다. 사유는 `data/duplicate-reviews.json`에 기록했습니다. 예를 들어 응축과 융해, 충전비와 충전밀도, 약제 보유량과 질량 유량은 다른 변화·물리량입니다. 단순 예외 목록이 아니라 양쪽 문항 내용 지문과 사유가 맞을 때만 검토된 후보로 인정합니다. 내용이 바뀌면 다시 검토합니다. 미해결 후보는 0쌍입니다.

문자 유사도와 기록 검사는 의미 중복·정답 정확성에 대한 완전한 증명이 아닙니다. 외부 전문가의 검토나 향후 오류 제보가 들어오면 근거를 다시 확인하여 수정해야 합니다.

## 법령·화학의 별도 확인

지정수량·농도·경계 포함 여부·AND/OR·예외·저장/운반/운송 구분·권한·시행일을 원문과 대조합니다. 시행규칙 별표 17 소화 적응성은 표와 비고를 함께 검토했습니다. 위험성 경고표지는 운송·운반 시의 별도 고시를 확보하여 구획실별 UN번호·그림문자 표시를 대조했습니다.

화학반응식 4개의 원자 수 보존, 계산 문항에 포함된 반응식 2개, 32개 계산을 자동 검산합니다. 원자 수 보존만으로 반응의 실제 성립 조건·속도·안전성이 검증되는 것은 아닙니다. 계산에서 쓰는 이상기체·이상용액·단열·완전해리 가정은 문제에 명시했습니다.

설치와 테스트는 원고를 생성하거나 자동 승인하지 않습니다. 출제 가능한 1,000개와 공식 전체 범위의 내부검수를 확보한 뒤 `npm run validate:release`를 통과해야 Pages 배포 단계로 진행합니다.
